# Contributing to PRKS

PRKS welcomes bug reports, fixes, documentation and tests. Start with
[Development Workflow](docs/wiki/Development-Workflow.md),
[AGENTS.md](AGENTS.md) and [DESIGN.md](DESIGN.md) for implementation rules.
Use a pull request for proposed changes; the maintainer reviews and approves
merges explicitly. Automated agents must not merge their own changes.

## Licensing contributions

The project distributes its original code and documentation under
[GNU AGPL version 3 only](LICENSE) (`AGPL-3.0-only`). By submitting
a contribution for inclusion, you agree to license **your contribution**
under that same license, unless a separate arrangement is clearly documented
and agreed by the maintainer. You retain your copyright; PRKS does not
require a copyright assignment or Contributor License Agreement.

Only submit code, documentation, and assets you have the right to contribute
under these terms. Do not copy in proprietary material or third-party code
whose terms conflict with AGPL, and do not remove copyright or license notices.
When adding vendored components, generated bundles, fonts, or other third-party
material, record the original authors, license and source, preserve required
license/NOTICE files, and update [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
Check binary assets and generated files separately from authored source.

Submissions are reviewed for correctness, provenance, license compatibility and
security. If you are unsure of the rights to contribute a change, raise that
question before submitting the pull request.
